# French and Spanish modes

The app has five language modes: Kreyòl, Kreyòl + English, **Français + English**, **Español + English**, and English.
French and Spanish are always shown with the English underneath, because the exam vocabulary is English.
Interface text (buttons, menus) is shown in French or Spanish only.

## How it works

- `data/i18n-fr.js` and `data/i18n-es.js` map each English string the app shows to its translation.
- They load only when someone picks that mode, so Kreyòl and English users don't download them.
- Any English string without a translation falls back to English, so nothing breaks; it just shows untranslated.
- Keys are the exact English text. Editing an English string (a fact change) drops its translation until it's redone.

## Checks to run after any content change

- `node tools/i18n-check.js .` lists missing and stale translations for both languages (exits 1 if anything is missing).
- `node tools/i18n-extract.js . > strings.json` exports every English string with an ID, for translating new content.
